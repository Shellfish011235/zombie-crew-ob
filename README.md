# Zombie Crew OB

A Vite + React mini-game collection: pick a survivor, then survive three apocalypse challenges.

## Games

1. **Outrun the Zombie Horde** — lane runner (↑↓ or W/S)
2. **Plate Licking Showdown** — click fast to clean your plate
3. **Bath Time Bubble Pop** — pop bubbles before time runs out

## Setup

```bash
npm install
npm run dev
```

## Player assets

Add character portraits to `public/players/`:

- `player1.png` through `player10.png`

## Scripts

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run preview` — preview production build
